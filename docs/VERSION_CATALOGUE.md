# Version catalogue

Source of truth for installable releases: the live output of `install.sh --list-versions`.
The official manifest is metadata only (versions, channels, changelog); it never authorises a
token that the backend did not offer.

## Real output shape

```
Titanfall 2 VR versions:
  Follow updates:
    1) latest     1.0.25  2026-10-24  [installed]  <- your choice
    2) beta       1.0.27  New features, may be unstable
  Stay on one version:
    3) multiplayer-beta-1.1.34  1.1.34  beta build
    4) 1.0.24     1.0.24  2026-10-23
Install one with:  ./install.sh --version NAME   (or just ./install.sh to pick from this list)
```

Verified live on 2026-11-12: 19 entries, `latest` 1.0.25 and `beta` 1.0.27.

## Mapping

| UI ordinal | Display | Backend token |
|---:|---|---|
| 1 | Stable / Latest | `latest` |
| 2 | Beta | `beta` |
| 3+ | Catalogue token (with resolved version) | exact token from the row |

Rules enforced in code and tests:

- Ordinals are generated by the app, never copied from the script's printed numbers.
- The token is the row name and is passed as a single `--version` argument.
- Tokens beginning with `-`, containing whitespace or control characters are rejected.
- Duplicate tokens are ignored and reported.
- Ordering: `latest` first, `beta` second, then the catalogue's own order.
- Reordering the catalogue cannot change a saved selection, because only the token is persisted.

## Parsing and failure modes

- ANSI escapes, CRLF, blank lines and unknown sections are tolerated.
- No rows parsed → empty catalogue with a diagnostic; the app refuses to install and never guesses.
- Backend invocation fails → cached catalogue is shown marked as cached, with the reason.
- If a previously selected token disappears, the UI says so and selects the first entry; it does
  not silently swap to a different pinned release.

## Caching

Catalogue JSON is cached under `${XDG_CACHE_HOME}/circuitlord-vrmodinstaller/catalogue.json`.
Cached data is labelled `Cached` in the UI and never presented as freshly verified.
